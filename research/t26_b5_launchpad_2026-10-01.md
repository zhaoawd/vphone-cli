## 6. 实现要点（事实）

- 命令白名单：`VPhoneLaunchpadReadOnlyCommand` 只能经三个工厂构造：`doctor(libraryRoot:)`（要求绝对路径）、`helperStatus`、`coreBundleVerify(version:)`（要求存储名格式）。`VPhoneLaunchpadCommandLine.run(_ command:)` 在启动进程前再次用 `isAllowed` 检查参数形状。Host Setup 与 Core Bundle 模型只调用该入口。
- `tests/test_launchpad_bundle.py`：从 FORBIDDEN 中拆出 `"doctor"|"helper"|"core-bundle"`，只允许出现在 `VPhoneLaunchpadReadOnlyCommand.swift`；`"cfw"|"install-bundle"|"verify-bundle"|"register"|"install"` 在全部 Launchpad 源码中禁止；新增 `test_b5_whitelist_builds_only_read_only_commands`，断言白名单文件中以这三个命令开头的数组只有三种前缀。
- doctor 映射：`doctorState` 对退出码 0/3/4/5 解码 JSON，要求 `schema == vphone.diagnostics`、`schema_version == 1`、`read_only == true`；其他退出码取 `Error:` 行作为原因。未知 severity 字符串显示为 `unknown`。severity 图标：ok 绿、warning 琥珀三角、error 红、unknown 琥珀问号。
- 运行时机：`VPhoneLaunchpadHostSetup` 与 `VPhoneLaunchpadCoreBundle` 初始化时不运行命令；`refresh()` 只由 sheet 的 `.task`（打开时）和 “Check Again”/“Verify Again” 按钮调用。`VPhoneLaunchpadMachineLibrary` 的 5 秒刷新未改动，不调用 doctor。
- 面板队列（`ded81cb`）：`present` 在已有其他面板时先置 `current = nil` 并记录 `queued`；`didDismiss`（sheet 的 `onDismiss`）不在本次更新中设置 `current`，而是创建 `Task` 在下一轮主 actor 设置；该 `Task` 保存在 `handoff` 供测试等待。
- 每次刷新向 stdout 写一行诊断：`[launchpad] host setup: doctor exit N, M findings, worst S; helper status ...`、`[launchpad] core bundle store: ...`，不含机器名与路径。
- 字符串：新增 39 个 key。11 个与上游 key 相同，沿用上游 zh-Hans（state `translated`）：Check Again、Checking…、Core Bundle、Done、Download and Install、Host Setup、Install、Install Local Build…、Installed、Not checked、Privileged helper。28 个 zh-Hans 由本批撰写，state 为 `needs_review`。doctor 字段名与取值（`worst`、`exit`、`ok/warning/unknown/error`、finding code、evidence 键）按原文显示，不翻译。

## 9. 事实、推断与未覆盖

事实：

- 本批 Launchpad 源码只构造三种 CLI 命令形状；源码扫描与单元测试同时检查。
- doctor 只在面板打开与用户点 “Check Again” 时运行；机器列表的周期刷新未改动。
- 本机冒烟中 Host Setup 显示 doctor 结论与 helper 状态原文，Core Bundle 面板显示内嵌工具链、存储不存在与禁用的安装入口。

推断：

- `VPhoneLaunchpadPanelQueue` 的 `Task` 在当前 sheet 关闭后执行，与上游 `ded81cb` 时序一致。依据是 `Task` 继承主 actor 隔离，在 `onDismiss` 所在更新结束后运行；单元测试只证明 `didDismiss` 当轮不设置 `current`，未在真实 sheet 切换中观察。

未覆盖：

- 两个面板之间的真实 sheet 切换（当前打开 Host Setup 时点 Core Bundle）未在 UI 中执行；冒烟只在启动时打开单个面板。
- “Check Again”“Verify Again” 按钮未在 UI 中点击；其调用的 `refresh()` 由单元测试覆盖。
- helper 可达（`helper protocol: N`）与存储中存在已安装版本的界面显示，只由替身 CLI 与临时目录覆盖；本机无已注册 helper 与存储目录。
- 多系统宿主上的 doctor 结果；doctor 与其他 VM 操作同时进行时的锁探测竞争。
- 28 条本地 zh-Hans 译文未经人工审阅（`needs_review`）。
- `LaunchServices`（`open`）方式启动未执行。
